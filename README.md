# university-1st-year-fse
Репозиторий для практический работ по основам программной инженерии.

Здесь расположены решения продвинутых задач практической работы №2:
- Задача B1 на чтение пути и масштаба из файла и вычисления расстояния всего пути и между локациями
- Задача B2 на чтение данных о температуре и скорости ветра из файла, вычислении охлаждения ветром и разницы температур и вывода отчёта в файл

Оба файла принимают на ввод файл через терминал, например, ```python B1.py inmap0.dat```
