# university-1st-year-fse
Репозиторий для практический работ по основам программной инженерии.

*Все скрипты, где используются файлы входных данных, принимают их через терминал, например, ```python B1.py inmap0.dat```*

Здесь расположены решения:
- продвинутых задач практической работы №2
   - Задача B1 на чтение пути и масштаба из файла и вычисления расстояния всего пути и между локациями
   - Задача B2 на чтение данных о температуре и скорости ветра из файла, вычислении охлаждения ветром и разницы температур и вывода отчёта в файл

- продвинутой задачи практической работы №3
   - Задача B1 на вычисление позиции мыши и кота и проверку исхода игры

- продвинутой задачи практической работы №4
   - Задача B1 на поиск ошибок в отчётах о погоде за месяц
